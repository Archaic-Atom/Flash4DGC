# Third-party code and publication

This repository is derived from the local 4DGC source distribution. Original
copyright notices remain in the source files. The upstream README is retained in
`upstream/4DGC_README.md`.

The Gaussian rasterizer, Gaussian Splatting-derived utilities, simple-knn and GLM
are third-party components. Preserve their embedded notices and bundled license
files. In particular, several files state non-commercial research/evaluation
terms. LPIPS code and pretrained weights retain their respective upstream terms.

The local 4DGC copy did not contain a root license file. This integration does not
grant a new license over upstream code. Before public redistribution, obtain or
confirm the upstream 4DGC license and all third-party redistribution conditions.
Do not apply a blanket MIT/Apache license to this entire tree without permission.

No data, pretrained models, private credentials, or remote repository history are
intentionally distributed here. Documentation of measured experiments is not a
license to redistribute their datasets or pretrained models.
